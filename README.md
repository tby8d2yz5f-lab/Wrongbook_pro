# 知错智能错题本：Ollama 本地免费版

这个版本在 Windows 本机运行 Ollama，生成错题详解、知识点和三道递进练习，并支持用本机视觉模型读取/校对题目图片。模型在第一次下载后可离线推理；不需要 API 密钥，也没有按次 API 费用。首次下载约需 3.3 GB（轻量版）或 6.1 GB（8B 版）；下载流量和电脑运行资源仍由本机承担。

## 新手安装与启动

1. 从 [Ollama Windows 下载页](https://ollama.com/download/windows)安装 Ollama。
2. 如果电脑还没有 Python，请从 [Python Windows 下载页](https://www.python.org/downloads/windows/)安装 Python 3.9 或更新版本，并在安装器首页勾选 **Add python.exe to PATH**。
3. 推荐双击 `准备本地模型.bat` 下载 `qwen3-vl:8b`（约 6.1 GB，生成能力较强）；电脑资源有限时，改用 `准备轻量模型.bat` 下载 `qwen3-vl:4b`（约 3.3 GB）。首次下载需要联网；Qwen3-VL 需要 Ollama 0.12.7 或更新版本。
4. 使用 8B 时双击 `启动错题本.bat`；使用 4B 时双击 `启动错题本_轻量版.bat`。浏览器会打开 `http://127.0.0.1:8765/`。
5. 在页面的“解析与变式训练”输入错题，点击“直接生成详解、知识点和练习”。也可在新增错题页面用本机 AI 识别题目图片。
6. 用完后关闭启动器窗口，停止本机服务。

## 手机在同一 Wi-Fi 下访问

1. 先在电脑上确认 Ollama 和所选模型可用。手机与电脑连接到同一个可信任的 Wi-Fi。
2. 使用 8B 双击 `启动错题本_手机访问.bat`；使用 4B 双击 `启动错题本_轻量版_手机访问.bat`。电脑浏览器仍会打开本机页面。
3. 如果 Windows 防火墙弹出提示，只允许“专用网络”访问。
4. 在电脑按 **Win + R**，输入 `cmd` 并回车；再输入 `ipconfig`。在当前连接的“无线局域网适配器 WLAN”部分找到“IPv4 地址”，例如 `192.168.2.35`。
5. 在手机浏览器输入 `http://电脑的IPv4地址:8765/`，例如 `http://192.168.2.35:8765/`。手机页面会调用电脑上的 Ollama。
6. 结束时关闭电脑上的启动器窗口。此模式仅用于可信任的家庭/个人 Wi-Fi；不要在公共 Wi-Fi 使用，也不要在路由器设置端口转发。

电脑和手机浏览器的错题数据分别保存在各自设备中，不会自动同步；需要在两台设备间迁移时使用 JSON 导出/导入。

## GitHub 使用方式

可以把整个文件夹上传到自己的 GitHub 仓库作为备份或分发源。但 GitHub Pages 只托管静态网页，不能运行本目录的 Windows 启动脚本和本机 AI 接口。需要使用免费本机 AI 时，请先把仓库下载到电脑，再双击上述 `.bat` 文件；只打开 GitHub Pages 网页不会启动本机 AI。

## 费用与隐私

- Ollama 与本地模型不按调用次数收费；下载模型需要网络和约 3.3 GB 磁盘空间。
- 错题 AI 解析和图像理解通过本机桥接服务交给本机 Ollama，不会发给 OpenAI、Mathpix 或本项目作者。
- 默认启动器只监听 `127.0.0.1`。可选手机启动器会开放同一局域网访问；仅在可信任 Wi-Fi 使用，并在 Windows 防火墙中只允许专用网络。关闭启动窗口即可停止服务。
- 页面内置的 Tesseract OCR 首次加载中文识别资源时仍可能需要联网；如希望完全离线，第一次使用前先联网打开 OCR 功能，让浏览器缓存所需资源。
- 模型回答可能有错，数学推导、图表读取和答案都应对照教材或教师讲解核验。

## 电脑要求与模型选择

`qwen3-vl:8b`（约 6.1 GB）默认用于较好的本机生成质量；`qwen3-vl:4b`（约 3.3 GB）更轻便。两者都支持文字和图片输入。运行速度和效果取决于电脑内存、显卡与处理器。即使使用 8B，本地模型的解答质量也可能不如更大的云端模型，练习答案仍要核验。

## 数据备份

错题保存在浏览器本地存储中。请定期使用软件的 JSON 导出功能，并将备份保存在安全位置。不要把包含个人错题的 JSON 提交到公开仓库。
